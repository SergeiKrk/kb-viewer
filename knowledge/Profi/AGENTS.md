## Конвенции страниц

### Entity page (категория услуг, конкурент)
```markdown
# Название
> One-liner

## Ключевые факты
## Связь с Сергеем
Как эта сущность влияет на поиск заказов.
## Связанные страницы
- [[другая-страница]]
```

### Strategy page (анализ, план)
```markdown
# Название
> Ключевой вывод

## Данные
## Анализ
## Рекомендации
## Связанные страницы
```

### Обязательные элементы
- **YAML frontmatter:** `tags: [tag1, tag2]`, `updated: YYYY-MM-DD`
- **Блок «Связанные страницы»** с `[[page]]` — на КАЖДОЙ странице
- **Обратная ссылка** из index.md

## Операции

### Ingest (новые данные)
1. Прочитать источник (скриншот, выгрузка, наблюдение)
2. Обсудить с Сергеем ключевые takeaways
3. Создать/обновить wiki-страницы
4. Обновить index.md
5. Добавить запись в log.md

### Query (вопрос)
1. Найти релевантные страницы через index.md
2. Синтезировать ответ
3. При значимом выводе — создать страницу в `strategy/` или обновить существующую

### Daily (ежедневная рутина)
1. Проверить новые заказы в категориях
2. Откликнуться на релевантные
3. Записать в `finance/orders-log.md`
