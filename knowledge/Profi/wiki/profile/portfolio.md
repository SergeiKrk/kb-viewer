# Портфолио

> Проекты для демонстрации на Профи.ру. Каждый кейс: задача → решение → результат.

## Основные кейсы

### 1. SamogonCalc — калькуляторы для самогонщиков

- **Стек:** Astro + React + MDX + Tailwind
- **Что сделано:** 12 калькуляторов, 86 страниц контента, SEO-оптимизация
- **Результат:** 10 000 посетителей/мес, органический трафик
- **Ссылка:** https://samogoncalc.ru

### 2. Конструктор гардеробных (онлайн)

- **Стек:** React + Konva.js + TypeScript
- **Что сделано:** drag&drop интерфейс, undo/redo, экспорт, полный цикл разработки
- **Результат:** работающий продукт, сложная интерактивная графика

### 3. AWX Solutions (финтех, коммерческий опыт)

- **Стек:** React + TypeScript + Contract First
- **Что сделано:** Middle Frontend в команде из 5 чел, реорганизация API-слоя, код-ревью, компоненты Telegram Mini App
- **Период:** ~1.5 года

### 4. SEO-анализ green-crown.ru

- **Что сделано:** полный SEO-аудит: конкуренты, запросы, позиции, технический аудит
- **Результат:** детальный отчёт для клиента

### 5. Пансионат «СимбирскЪ» — макет лендинга

- **Стек:** HTML/CSS макет
- **Что сделано:** дизайн 18 блоков на основе анализа 13 конкурентов (РФ + США)
- **Результат:** визуальный макет для обсуждения с заказчиком

## Как показывать

1. **Скриншоты:** 2-3 на проект (десктоп + мобильная версия)
2. **Живые ссылки:** samogoncalc.ru обязательно
3. **Цифры:** трафик, конверсия, сроки — конкретные метрики
4. **Для NDA-проектов:** описание без названия компании («финтех-проект, Middle Frontend»)
