# Ценовая стратегия — Profi.ru

> Анализ рынка Profi.ru (август 2026) и рекомендованные цены для Сергея Крюкова.
> Позиционирование: Product Engineer (React/TypeScript, 3 года), не дешёвый фрилансер.

## Рынок Profi.ru — срез цен

Реальные заказы августа 2026:

| Услуга | Бюджет |
|--------|--------|
| WordPress сайт | 500 ₽ |
| Настройка бота | 8 000 ₽ |
| Squarespace правки | 15 000 ₽ |
| SEO-продвижение | 15 000 – 50 000 ₽ |
| Разработка ПО | 20 000 – 50 000 ₽ |
| Программирование Codesys | 21 000 ₽ |
| Битрикс (интернет-магазин 10K товаров) | 200 000 ₽ |

**Ключевой принцип:** не конкурировать с демпингерами (500 ₽ за WordPress). Преимущество — качество, финтех-опыт, проект на 10K посетителей.

| Услуга | Почему нет |

| Интернет-маркетинг | Не специализация. Ты SEO-аудит, не маркетинг |
| Blockchain-разработчики | Нет опыта в web3 |
| Data scientist | Другая профессия |

| Внедрение DevOps | CI/CD — да, но DevOps это IaC, Docker, K8s |
