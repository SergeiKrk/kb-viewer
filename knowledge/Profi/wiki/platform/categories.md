## Стратегия для Сергея

**Приоритетные категории (в порядке убывания):**

1. **IT-аутсорсинг → Frontend-разработка, Вёрстка, Разработка сайтов** — прямой профиль
2. **IT-аутсорсинг → Разработка Telegram-ботов** — есть опыт (AWX)
3. **IT-аутсорсинг → Техническая поддержка сайтов** — низкий порог входа
4. **Маркетинг → SEO-продвижение** — есть кейсы (green-crown, пансионат)
5. **Работа с текстами → SEO-тексты** — дополнительный заработок
6. **Репетиторы → Программирование** — долгосрочные клиенты
