# Разработка SPA (React + TypeScript)

> Single Page Applications на React 18/19 + TypeScript. Основная услуга — полный цикл: от архитектуры до деплоя.

## Что предлагаю

- Разработка с нуля: админки, дашборды, личные кабинеты, интерактивные сервисы
- Миграция с jQuery/ vanilla JS на React
- Рефакторинг легаси-кода
- Feature-Sliced Design (FSD) архитектура
- Интеграция с REST API / tRPC
- Управление состоянием: TanStack Query, Zustand
- Тестирование: Vitest + React Testing Library

## Кейсы

| Проект | Что сделано |
|--------|-------------|
| **AWX Solutions** (финтех, 1.5 года) | Middle Frontend: реорганизация API-слоя, код-ревью, компоненты Telegram Mini App, линтинг |

## Стек

- **Язык:** TypeScript (strict, generics, discriminated unions)
- **Фреймворк:** React 18/19, Next.js (App Router), Astro
- **Сборка:** Vite
- **Стили:** Tailwind CSS, DaisyUI
- **Состояние:** TanStack Query, Zustand, URL-as-state
- **Тесты:** Vitest, React Testing Library, Playwright
- **CI/CD:** GitHub Actions

## Цены (ориентир)

- Небольшая SPA (1-3 экрана): 50 000 – 100 000 ₽
