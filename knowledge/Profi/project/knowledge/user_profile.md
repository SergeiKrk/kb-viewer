### 🔹 Самая сложная задача (восстановлено)

**Кейс: реорганизация API-слоя в финтех-проекте (AWX Solutions)**

Проблема: В проекте на React + TypeScript было около 40 эндпоинтов, каждый описан вручную — типы ответов не совпадали с реальностью, данные падали в runtime. Другие разработчики пробовали править точечно, но ошибки возникали снова и снова.

Что сделал: Предложил и внедрил Contract First подход — генерировать TypeScript-типы из OpenAPI-спек. Поднял swagger-ui рядом с проектом, написал скрипт кодогенерации. За 2 недели все 40 эндпоинтов были описаны в спеке, типы перегенерированы, баги с несовпадением данных исчезли полностью.

Результат: runtime-ошибки на продакшене снизились на 90%. Команда приняла подход как стандарт для всех новых эндпоинтов.

### 🔹 Самый сложный баг (восстановлено)

**Кейс: drag & drop глючил на touch-устройствах (конструктор гардеробных)**

Проблема: В React + Konva.js приложении перетаскивание элементов работало идеально на десктопе, но на iPad и Android-планшетах элементы «залипали» — не отпускались после touch-end. Клиент жаловался, что мобильная версия сломана.

Диагностика: 2 дня исследовал. Оказалось — Konva.js использует pointer events, но на touch-устройствах порядок событий pointerup/touchcancel/lostpointercapture отличался от десктопа. Плюс React 18 strict mode в dev-режиме вызывал двойной mount, из-за чего обработчики событий вешались дважды.

Решение: Переписал слой обработки событий — unified event handler с явным трекингом состояния pointer capture. Добавил AbortController для очистки обработчиков при размонтировании. Написал e2e-тест на Playwright с эмуляцией touch.

Результат: drag & drop заработал на всех устройствах. Баг воспроизводился и у других пользователей Konva.js — решение оформил как reusable хук.
