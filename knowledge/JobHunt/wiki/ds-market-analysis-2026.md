# Data Scientist — анализ рынка РФ (июль 2026)

## Общий размер рынка

Прямой поиск по заголовкам вакансий (`search_field=name`, РФ):

| Специализация | Вакансий |
|---|---|
| Data Scientist | 170 |
| AI Engineer | 166 |
| ML Engineer | 155 |
| Data Analyst | 150 |
| LLM | 111 |
| Computer Vision | 54 |
| NLP | 33 |
| Machine Learning | 20 |
| Deep Learning | 9 |
| Generative AI | 8 |

**Ядро DS-рынка (Data Scientist + ML Engineer + AI Engineer) — около 490 вакансий.** С учётом пересечений, реальный рынок DS/ML/AI — **400-500 позиций.**

Для сравнения: fullstack-рынок РФ — 330 вакансий. Рынок DS заметно больше.

## Структура по грейдам (Data Scientist)

| Грейд | Вакансий | Доля |
|---|---|---|
| Senior | 54 | 32% |
| Middle | 24 | 14% |
| Junior | 10 | 6% |
| Без грейда | 82 | 48% |

**Senior bias такой же, как на fullstack-рынке:** Senior > Middle в 2.3 раза. Junior — всего 6% явных позиций. Это рынок для опытных специалистов.

## Удалёнка

Data Scientist удалённо: **66 из 170 = 39%.** Ниже, чем fullstack (58%). DS чаще требует присутствия — вероятно, из-за работы с чувствительными данными и on-premise инфраструктурой.

## Тренды: LLM взрывной рост

**LLM — 111 вакансий в заголовке.** Это больше, чем Computer Vision (54) и NLP (33) вместе взятые. Рынок разогрет хайпом вокруг генеративных моделей.

При этом Generative AI как термин почти не используется в заголовках (8) — работодатели пишут «LLM», а не «GenAI».

**Вывод:** если заходить в DS сегодня — то через LLM/GenAI-трек. Это самый горячий сегмент с наибольшим отношением спрос/конкуренция.

## Python — не конкурентное преимущество, а гигиенический минимум

Python ML в заголовках — всего 11 вакансий. Python подразумевается по умолчанию в DS, это не дифференциатор.

## Макро-контекст

- hh.индекс: **8.3** — рынок работодателя (высокая конкуренция соискателей)
- Вакансии к прошлому году: **−17…−30%** (падение по всем профобластям)
- Прирост вакансий к предыдущему месяцу: **+8%** (возможное начало восстановления)

## Ключевые выводы

1. **Рынок DS больше fullstack** — 400-500 vs 330 вакансий
2. **LLM — точка входа №1** — 111 вакансий, растущий тренд, меньше конкуренции чем в классическом DS
3. **Senior bias** — Senior:Middle = 2.3:1, рынок для опытных
4. **Удалёнка ниже средней** — 39% vs 58% fullstack. DS чаще офис/гибрид
5. **Python — must-have, не преимущество.** Дифференцироваться через: LLM-фреймворки (LangChain, LlamaIndex), MLOps (MLflow, Kubeflow), облака (AWS/GCP), vector DB, prompt engineering
6. **Компетенции на пике спроса:** LLM/RAG-разработка, fine-tuning, MLOps, Computer Vision (стабильный спрос: 54)

## Стратегическая рекомендация

Для React/TS-разработчика, рассматривающего переход в DS:

**Приоритеты входа:**
1. **LLM-инженерия** — самый горячий трек, 111 вакансий, низкий порог входа для программиста (API, prompt engineering, RAG)
2. **MLOps/Data Engineering** — мост между разработкой и DS, ценится инженерный бэкграунд
3. **Классический DS** — высокий порог (математика, статистика), высокая конкуренция

**Не рекомендую:** классический DS с нуля — потребует годы на математику, высокий риск не дойти до job-ready уровня.
