# Data Scientist vs Fullstack — сравнительный анализ рынка РФ

## 1. Размер рынка

| Направление | Вакансий (заголовки) | Примечание |
|---|---|---|
| **DS-ядро** (DS + ML + AI Engineer) | **~490** | Data Scientist 170, ML Engineer 155, AI Engineer 166 |
| **Fullstack** | **330** | Суммарно fullstack-вакансий |
| DS LLM-трек | 111 | Самый горячий подсегмент |
| DS Computer Vision | 54 | Стабильный спрос |
| React + Node.js | 16 | Доминирующая fullstack-связка |

**Рынок DS в 1.5× больше fullstack-рынка** по прямым замерам. Но есть нюанс: DS-вакансии (Data Scientist + ML Engineer + AI Engineer) частично пересекаются — реальный рынок скорее **400-500 позиций**.

## 2. Грейды: Senior bias

| Грейд | Fullstack | Data Scientist |
|---|---|---|
| Senior | 61 (18%) | 54 (32%) |
| Middle | 24 (7%) | 24 (14%) |
| Junior | — | 10 (6%) |
| Без грейда | — | 82 (48%) |

**Senior bias выражен в обоих направлениях**, но в DS он жёстче: Senior:Middle = 2.3:1 против ~2.5:1 у fullstack. 

Однако key insight: **в DS половина вакансий без явного грейда** — это говорит о том, что работодатели ищут «просто Data Scientist» и готовы смотреть на реальные навыки, а не на лейбл. В fullstack такого нет — там грейд почти всегда указан.

## 3. Удалёнка

| Параметр | Fullstack | Data Scientist |
|---|---|---|
| Удалённых вакансий | 190 | 66 |
| Доля удалёнки | **58%** | **39%** |
| Офис/гибрид | 42% | **61%** |

**Fullstack в 1.5× более удалённый.** DS чаще требует присутствия — работа с чувствительными данными, on-premise GPU-кластеры, необходимость физического доступа к инфраструктуре.

Для соискателя из региона это критично: **fullstack даёт 58% шанс на удалёнку, DS — только 39%.**

## 4. Зарплаты

Общие цифры Хабр Карьеры (все IT, 43 822 анкеты):

| Грейд | Все IT | Fullstack (оценка) | DS (оценка, +20%) |
|---|---|---|---|
| Junior | 95k | 100-120k | 120-150k |
| Middle | 173k | 180-250k | 220-280k |
| Senior | 303k | 300-380k | 350-420k |
| Lead | 378k | 380-450k | 430-500k+ |

**DS платит больше на всех грейдах**, особенно на senior+. Разрыв: **+15-30% в пользу DS.**

Но есть нюанс: fullstack-разработчик с React/TS уже на middle-грейде (~180-250k), а для DS придётся начинать с junior (120-150k) — **временной провал в доходе на 1-2 года.**

## 5. Порог входа (для React/TS-разработчика)

| Критерий | Fullstack (Node.js) | Data Scientist |
|---|---|---|
| **Время до job-ready** | 3-6 мес | 12-24 мес |
| **Использование текущих навыков** | JS/TS — напрямую | Не используются |
| **Новое для изучения** | Node.js, SQL, Docker | Python, матстат, ML, SQL, MLOps |
| **Математический барьер** | Низкий | Высокий (лин. алгебра, тервер, оптимизация) |
| **Конкуренция на входе** | Средняя | Высокая (много выпускников DS-курсов) |
| **Риск не дойти** | Низкий | Высокий |
| **Трек с низким порогом** | Весь fullstack | LLM-инженерия (API, RAG) |

**Fullstack на Node.js — естественное продолжение для React-разработчика.** JS/TS-навыки используются напрямую, порог входа — 3-6 месяцев. DS требует начинать почти с нуля.

**Исключение — LLM-инженерия:** это мост между разработкой и DS. API-интеграции, RAG, prompt engineering — здесь инженерный бэкграунд ценится, математики нужно меньше. 111 вакансий, растущий тренд.

## 6. Тренды и будущее

| Параметр | Fullstack | Data Scientist |
|---|---|---|
| Основной драйвер | Веб-приложения, SaaS | AI/LLM-хайп, автоматизация |
| Растущий сегмент | Next.js fullstack, TypeScript | LLM, GenAI, MLOps |
| Падающий сегмент | PHP fullstack, jQuery | Классическая статистика, ETL |
| Стабильность спроса | Высокая (веб никуда не денется) | Средняя (хайп цикличен) |
| Риск автоматизации | Низкий | Средний (AI-инструменты для DS) |

**Fullstack стабильнее.** Веб-приложения — базовая потребность бизнеса. DS — более волатильный рынок, зависит от инвестиционных циклов в AI.

## 7. Стратегический вывод

### Путь А: Fullstack Node.js (рекомендуемый)
- ⏱ 3-6 месяцев до job-ready
- 💰 Middle: 180-250k, Senior: 300-380k
- 🏠 58% удалёнки
- 📈 Стабильный, предсказуемый рост
- 🔄 JS/TS-навыки используются напрямую

### Путь Б: LLM-инженерия (альтернативный)
- ⏱ 4-8 месяцев до job-ready
- 💰 Middle: 220-280k (выше fullstack)
- 🏠 39% удалёнки (хуже)
- 📈 Горячий тренд, но волатильный
- 🔄 Инженерный бэкграунд ценится

### Путь В: Классический DS (не рекомендуется)
- ⏱ 18-24 месяца до job-ready
- 💰 Высокий потолок, но долгий путь
- 🏠 39% удалёнки
- ⚠️ Высокий риск не дойти
- 🔄 Начинать почти с нуля

### Итоговая рекомендация

**Fullstack Node.js — оптимальный маршрут для React/TS-разработчика.** Минимальный порог, максимальная конвертация текущих навыков, высокая доля удалёнки, стабильный спрос.

**LLM-инженерия — альтернатива для тех, кому интересен AI.** Как второй трек параллельно с fullstack, не вместо. Даёт +20% к зарплате и выход на горячий рынок, но жертвует удалёнкой и требует времени на изучение.

**Связка fullstack + LLM — убийственная комбинация.** Fullstack-разработчик, который умеет интегрировать LLM в продукты — это редкий и дорогой специалист. Рынок таких почти не видел, конкуренция минимальна.
