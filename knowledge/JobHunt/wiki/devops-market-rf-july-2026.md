## 9. Ключевые выводы и рекомендации

### Для входа в DevOps

1. **DevOps — не для новичков.** 2% junior-вакансий — это сигнал: без опыта администрирования или разработки в DevOps не войти. Сначала — системный администратор, разработчик или QA-автоматизатор, потом — DevOps.

2. **Технологический фундамент:** Docker + Kubernetes + CI/CD — без них не рассматривают. Это «три кита», которые нужно знать на уровне уверенного Middle.

3. **Инфраструктура как код:** Terraform (417 вакансий) — растущий стандарт. Ansible (970) — стабильный спрос. Стоит учить оба, начиная с Ansible (проще порог входа).

4. **Российская специфика:** Yandex Cloud (226) вместо AWS/Azure. GitLab CI (1 183) вместо GitHub Actions. Если цель — работа в РФ, фокус на этом стеке.

### Для роста в DevOps

5. **DevOps Lead — 461 000 ₽.** Это на 22% выше общего IT Lead. Глубокая экспертиза в инфраструктуре оплачивается выше среднего по рынку.

6. **SRE и Platform Engineer** — ниши с меньшей конкуренцией. SRE (91 вакансия) — более высокая зарплата, но и более высокий порог входа (требуется опыт разработки + администрирования).

### Для Сергея (фронтендер, смотрит на DevOps)

7. **DevOps для фронтендера — это не отдельная профессия, а расширение компетенций.** Как фронтендер, ты не станешь DevOps-инженером за месяц. Но:
   - Docker + Docker Compose — **обязательно** (для локальной разработки и деплоя)
   - CI/CD (GitLab CI / GitHub Actions) — **очень желательно** (пайплайны сборки и деплоя фронтенда)
   - Nginx, домены, SSL — **базово** (для настройки продакшн-окружения)
   - Kubernetes — **опционально** (для фронтендера избыточно, если нет цели стать DevOps)
