## Хронология

### Этап 1: Бот-опрос (15.07.2026)

**Вопрос 1 — SQL и базы данных:**

> Оцените, пожалуйста, Ваш опыт работы с реляционными базами данных. Приходилось ли Вам самостоятельно писать SQL-запросы, например, для SQLite?

Да, опыт работы с реляционными базами данных есть. Настраивал и сопровождал CMS интернет-магазина, где приходилось самостоятельно писать SQL-запросы — выборки с JOIN'ами, фильтрацию, агрегацию для отчётов. Понимаю разницу между ORM и прямыми запросами, знаком с индексами и оптимизацией на базовом уровне. В повседневной фронтенд-работе с базами напрямую сталкиваюсь реже, но при проектировании API-контрактов с backend-командой в AWX понимание структуры БД было необходимо — обсуждали форматы данных, связи, ограничения.

**Вопрос 2 — Архитектурные решения:**

> Расскажите, пожалуйста, о ситуациях в Вашей практике, когда Вам приходилось самостоятельно принимать архитектурные или технические решения и нести полную ответственность за реализацию проекта или крупного функционала.

В AWX, когда переходили на новое API, я взял на себя реорганизацию фронтенда: выделил слой работы с данными отдельно от UI-компонентов, чтобы запросы и отрисовка не были перемешаны. Решение принимал сам — как разбить, в каком виде хранить промежуточные данные. Позже вся команда работала по этой структуре.

Работали по схеме Contract First: архитектор выдавал спецификации API-контрактов, а мы с backend-командой параллельно разрабатывали свои части. В этом процессе я участвовал в обсуждении контрактов со стороны фронтенда — мог предложить, например, упростить вложенность ответа, чтобы не гонять лишние данные. Это не архитектура уровня системы, но решения, влияющие на удобство и производительность фронтенда.

Так же делал новые разделы дашбордов для аналитики на Vue.js. Задача ставилась на уровне «нужны такие-то отчёты», а как именно организовать компоненты, данные и взаимодействие с API — решал самостоятельно.

**Вопрос 4 — Удалёнка:**

> Подходит ли Вам формат полностью удаленной работы на постоянной основе? Есть ли у Вас всё необходимое для этого (стабильный интернет, рабочее место)?

Да, удалёнка — отличный вариант, всё необходимое для работы есть.

**Вопрос 5 — Git и деплой:**

> Опишите, пожалуйста, Ваш опыт использования Git. Также уточните, занимались ли Вы процессами развертывания приложений (деплоем)?

С Git работаю постоянно. В AWX — ежедневно: ветки, pull requests, code review, решение конфликтов. Плюс был опыт с GitLab — настройка CI через .gitlab-ci.yaml, но недолго, базово.

В собственных проектах — порядка 30 репозиториев на GitHub, от пет-проектов до небольших коммерческих сайтов. Git — мой основной инструмент контроля версий, без него уже не представляю работу.

По деплою: на своих проектах занимался сам — выкладка на shared-хостинг через FTP, настройка Nginx для SPA, базовый CI/CD через GitHub Actions (линтер → сборка → деплой). В AWX этим занималась отдельная DevOps-команда, я с их стороны процесс понимаю, но руками не настраивал.
