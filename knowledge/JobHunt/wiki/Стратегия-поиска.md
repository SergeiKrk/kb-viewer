# Стратегия поиска работы — frontend, удалённо

## Цель
Удалённая работа frontend-разработчиком в российской компании. Приоритет — финтех (опыт в AWX). Также интересны: b2b-разработка на заказ, продуктовые компании с внутренней разработкой.

## Ключевые навыки
- Фронтенд: Astro, React, TypeScript, MDX, Tailwind, DaisyUI
- Инструменты: Git, GitHub Actions, FTP-деплой, Bash, Python
- Смежное: SEO-оптимизация, контент-менеджмент, PWA
- Проект в портфолио: samogoncalc.ru (Astro, 65+ страниц, 10 калькуляторов, 300 чел/сут)
