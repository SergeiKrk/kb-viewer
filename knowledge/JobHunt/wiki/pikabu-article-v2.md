# Я 15 лет в IT, и меня достало делать «кнопочки». Пошёл на hh.ru, пересчитал все вакансии и выбрал бэкенд. Спойлер: PHP ещё жив

Всем привет. Сергей, Ульяновск, в IT с середины 2000-х: jQuery, ExtJS, Backbone, Angular первых версий, сейчас — React и TypeScript. Коммерческий фронтенд — три года, до этого много всего разного.

Полгода назад понял: упёрся. Не в деньги — в развитие. Делаешь сложные формочки с микрофронтендами и стейт-машинами, а хочется понимать систему целиком. Почему API тормозит, как данные идут в базу, что происходит под капотом.

Fullstack. Но какой бэкенд?

На YouTube меня ждали ролики «ТОП-5 ЯЗЫКОВ, ПОКА НЕ ПОЗДНО» — парень с укладкой, написавший Hello World три месяца назад. Я пошёл на hh.ru и начал считать сам. Эта статья — результат.

---

## Как я считал

Площадки:
- **hh.ru** — только прямые совпадения в названиях вакансий, без поиска по описанию. Пятнадцать запросов: Python, Java, Go, PHP, Node.js, C# — и их комбинации с fullstack и React. Фильтр — РФ, без ограничений по зарплате.
- **Хабр Карьера** — 43 716 анкет, июль 2026. Брал медианы, а не средние: одна зарплата в Яндексе не искажает общую картину.

Дата сбора: **14–20 июля 2026**. Всё вручную. Скриптов не писал.

Что я не могу гарантировать:
- Поиск по заголовкам даёт заниженные абсолютные цифры. Вакансия «Senior разработчик» без указания языка в названии не попала в выборку. Но пропорции между языками этот метод держит — смещение работает одинаково для всех.
- Это **срез одной недели**, а не годовой тренд. Через полгода цифры могут быть другими.
- Часть рынка — это закрытые вакансии (внутренний найм, рекомендации), они вообще не видны.
- Региональные перекосы: в Москве картина может отличаться от Ульяновска.

Тем не менее, для принятия личного карьерного решения точности хватает.

Python вдвое опережает третий C# — выглядит как безоговорочный лидер. Но я открыл эти 519 вакансий. Значительная часть — Data Science, ML, нейросети, автоматизация. Не веб. Python-разработчик в банке может не писать API вообще — он обучает скоринговые модели.

**Вывод:** сырые цифры по рынку в целом врут применительно к fullstack. Нужно смотреть на другую выборку.

Ещё одна деталь: Node.js и TypeScript. Если считать их вместе (TypeScript-бэкенд — это NestJS или Next.js, технически тот же Node.js), получается 115 — третье место после Python и Java. По-моему, честнее так и считать, но дальше я разделяю их для прозрачности.

Go — 141 вакансия. Много для 15-летнего языка. PHP — 207, и это тот самый PHP, на котором «уже никто не пишет» лет десять как.

Ruby — 15. Закончился.

## Fullstack-срез: картина переворачивается

Отфильтровал вакансии, где в заголовке или первом абзаце описания явно указана связка «фронтенд + бэкенд». Потребовалось вручную пересмотреть около 200 вакансий — некоторые заголовки обманчивы, внутри может быть чистый бэкенд.

> 📊 **[ВСТАВИТЬ КАРТИНКУ: fullstack_bar.png]**

- PHP — 30
- Python — 29
- Java — 28
- C#/.NET — 21
- Node.js — 15
- TypeScript — 10
- Go — 2
- Ruby — 1

PHP вышел на первое место. Я перепроверил — цифра честная.

**Вывод, которого я не ожидал:** PHP — лидер fullstack не потому, что это лучший язык для веба. А потому что Laravel-экосистема исторически сложилась как fullstack: фреймворк даёт и бэкенд, и Blade-шаблоны из коробки. В вакансиях на Laravel работодатель часто ищет одного человека на всё — от базы до фронта. Это артефакт экосистемы, а не сигнал «учить PHP в 2026».

Node.js + TypeScript при сложении дают 25 — второе место. Честно говоря, я ожидал меньшего. Думал, fullstack-вакансии заняты PHP и Java, а Node.js — нишевая история. Оказалось — нет.

Go — 2 fullstack-вакансии на всю страну. Это не случайность. Go проектировался для микросервисов и инфраструктурного кода, а не для fullstack. Искать fullstack на Go — всё равно что искать спорткар с кузовом универсал.

### Контекст рынка, который стоит держать в голове

- Всего fullstack-вакансий в выборке: 330
- Удалёнка: 190 (58%)
- Senior: 61, Middle: 24. **В 2,5 раза больше senior-позиций, чем middle**
- hh.индекс: 8,3 — конкуренция высокая, рынок работодателя
- Динамика: вакансий +8%, резюме −2% — медленный разворот

**Вывод:** fullstack — не точка входа. Сначала стань кем-то одним, потом расширяйся. Статистика это подтверждает: middle-позиций почти нет, рынок ждёт опытных.

## React + бэкенд: ключевой график

Вот ради чего всё затевалось. Какие бэкенды реально ищут в паре с React? Не «упомянут где-то в требованиях», а прямо в заголовке или первом абзаце:

> 📊 **[ВСТАВИТЬ КАРТИНКУ: react_combos.png]**

- React + Node.js — 16
- React + PHP — 9
- React + Python — 8
- React + Java — 6
- React + .NET — 5
- React + Go — 1

Node.js — почти двукратный отрыв.

**Вывод:** Node.js не самый массовый бэкенд-язык в целом. Но для React-фронтендера, который хочет в fullstack, он — самый частый выбор работодателей. 16 против 1 у Go — это не погрешность, это паттерн.

Почему это логично?

1. **Один язык.** TypeScript на клиенте и сервере. Типы переиспользуются, не надо переключаться. DTO описал один раз — работает везде.
2. **Next.js стирает границу.** API routes, Server Components, Server Actions — разработчик на Next.js уже пишет бэкенд, часто сам того не замечая.
3. **NestJS для тех, кому Next.js маловат.** Модульная архитектура, dependency injection, guards, interceptors — enterprise-уровень, но на знакомом TypeScript.
4. **Общая экосистема.** Zod, date-fns, shared-библиотеки в монорепе. Меньше дублирования, быстрее разработка.

React + PHP (9 вакансий) — как правило, Laravel на бэке + React как админка или SPA. Рабочая связка, особенно в e-commerce.

React + Go (1 вакансия) — если кто-то видел такую вживую, напишите. Мне правда интересно, что за проект.

## Деньги: что не так с медианой

> 📊 **[ВСТАВИТЬ КАРТИНКУ: salaries.png]**

Медианные зарплаты fullstack-разработчиков, Хабр Карьера, 43 716 анкет:

- Intern — 66 000 ₽
- Junior — 95 000 ₽
- Middle — 177 000 ₽
- Senior — 303 000 ₽
- Lead — 378 000 ₽

Разрыв Middle → Senior: 126 тысяч. Junior → Middle: 82 тысячи. Senior → Lead: 75 тысяч.

**Вывод:** самый крутой скачок — между middle и senior. Рынок платит за глубину, а не за ширину. Fullstack-middle, который «всё понемногу», ценится сильно меньше, чем fullstack-senior, который глубоко знает оба направления.

Что эти цифры не показывают:
- Разброс внутри грейдов огромный. Senior fullstack в региональной веб-студии и senior fullstack в финтехе — разные вселенные.
- Хабр Карьера смещена в сторону высокооплачиваемых специалистов (те, кто получает мало, реже заполняют анкеты).
- Зарплаты в разрезе языков скрыты за регистрацией. Не могу сказать, получает ли PHP-senior столько же, сколько Node.js-senior. Подозреваю, что нет, но без доказательств.

## Удалёнка: 58%, и это не предел

190 из 330 fullstack-вакансий — удалённые. Для меня это критично: я в Ульяновске, ближайшие офисы крупных IT-компаний — Казань или Самара. С удалёнкой это не проблема.

Любопытная деталь: большинство удалённых fullstack-позиций — аутсорсинг и продуктовые стартапы. Enterprise-сектор (банки, телеком) пока осторожнее. Если ваша цель — Java в банке, удалённых вакансий будет заметно меньше, чем в среднем по рынку.

## Что я выбрал и почему (вместо заключения)

Node.js + NestJS + TypeScript.

Не «потому что модно». Пять причин, которые для меня перевесили:

1. **Язык один.** TypeScript — мой рабочий инструмент больше пяти лет. Декораторы `@Controller()` в NestJS — продолжение того, что я уже знаю, а не новый мир.

2. **16 вакансий React + Node.js против 1 у Go.** Это конкретный сигнал: работодатели, которым нужен fullstack на React, ждут Node.js на бэке.

3. **Потолок высокий.** Простой CRUD пишется за вечер. Дальше — CQRS, event-driven, микросервисы на Kafka/NATS. Расти есть куда.

4. **Next.js как трамплин.** Server Actions и API Routes — это уже бэкенд. Переход к NestJS — просто структурирование тех же концепций.

5. **Общая кодовая база.** Типы, валидация, утилиты — без дублирования.

Что дальше — не знаю. Возможно, через год-два вторым языком возьму Python + FastAPI, как мост в AI/ML-проекты. Но это пока предположение.

## Практические рекомендации

**React/TypeScript-фронтендер → Node.js, NestJS.** Язык знаком, синергия максимальная, рынок подтверждает.

**Data Science / AI → Python, FastAPI.** Строить веб-приложения вокруг ML-моделей — редкая комбинация. Но вакансий меньше, чем в чистом вебе.

**Enterprise → Java / C#.** Стабильно. Высокий чек. Порог входа выше, экосистема тяжелее.

**Highload, инфраструктура → Go.** Fullstack-позиций почти нет, но как чистый бэкенд — мощный выбор.

**Максимум вакансий прямо сейчас → PHP, Laravel.** 30 позиций. Но переход из TypeScript-мира будет культурным шоком.

## Что я вынес для себя

**Node.js — не самый большой рынок вообще, но самый логичный для React-фронтендера.** 16 вакансий против 1 у Go. Не погрешность.

**Fullstack — не для старта.** 61 senior против 24 middle. Сначала глубина, потом ширина.

**Один язык на клиенте и сервере — реальное преимущество.** Не просто удобство. Скорость разработки, меньше ошибок, общий тулинг.

**Цифры — не истина.** Это срез июля 2026. Через полгода пересчитаю — возможно, картина изменится.
