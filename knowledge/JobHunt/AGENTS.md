# AGENTS.md — JobHunt

## Domain
Поиск удалённой работы frontend-разработчиком в российских компаниях. Фокус: организации, занимающиеся b2b-коммерческой разработкой ПО или разработкой внутренних продуктов. Приоритетная отрасль — финтех.

## Language
Все записи на русском. Технические термины — на языке оригинала с русским пояснением.

## Structure
```
JobHunt/
├── AGENTS.md        ← Этот файл
├── raw/            ← Исходные данные (списки компаний, вакансии, экспорт из HH.ru/хабр.карьера)
├── wiki/           ← Обработанные страницы (карточки компаний, анализ рынка, стратегия поиска)
├── index.md        ← Каталог wiki-страниц с аннотациями
└── log.md          ← Хронология операций
```

## Conventions
- YAML frontmatter: `title`, `date`, `tags`, `category`, `source_count`
- Wiki-ссылки: `[[wiki/PageName]]` (префикс `wiki/` обязателен)
- Категории: `company` (карточка компании), `analysis` (аналитика рынка), `strategy` (стратегия поиска), `meta`
- Страницы компаний именуются по названию компании (русское или английское, как принято)

## Page template — карточка компании
```yaml
---
title: "Название компании"
date: YYYY-MM-DD
tags: [финтех, b2b, продукт, frontend]
category: company
status: target | contacted | interview | rejected | hired
---
```

Секции: Контакты, Стек, Продукты, Офисы/удалёнка, Вакансии, Заметки.

## Workflows
1. **Сбор**: поиск компаний → сохранение сырых данных в `raw/`
2. **Обработка**: создание карточки в `wiki/`, заполнение по шаблону
3. **Анализ**: страницы анализа рынка, стратегии поиска, воронки
4. **Линт**: после крупных изменений — проверка битых ссылок и сиротских страниц
