# Черный список работодателей

_Последнее обновление: 2026-06-08_

## Причины включения в черный список

1. **Собственные площадки для поиска работы** — компании предпочитают кандидатов с своих платформ
2. **Высокий процент отказов** — статистически низкий отклик на отклики
3. **Дублирование вакансий** — одни и те же позиции на разных площадках

## Как использовать

При поиске вакансий исключать компании из этого списка:
- Добавить `&company_id=!COMPANY_ID` в URL поиска
- Или фильтровать результаты вручную

## Обновление списка

Добавлять новых работодателей при:
- Получении 3+ отказов подряд от одной компании
- Обнаружении собственной платформы для поиска работы
- Дублировании вакансий на разных площадках
