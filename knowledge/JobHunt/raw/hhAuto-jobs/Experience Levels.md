# Уровни опыта для分类 вакансий

_Последнее обновление: 2026-06-08_

## Классификация по опыту

| Уровень | Опыт | Зарплата (удалённо) | Описание |
|---------|------|---------------------|----------|
| **Junior** | 0-1 год | 80-150k | Начинающие разработчики |
| **Middle** | 1-3 года | 120-200k | Разработчики с опытом |
| **Middle+** | 3-6 лет | 180-300k | Опытные разработчики |
| **Senior** | 6+ лет | 250-400k | Старшие разработчики |
| **Lead/Principal** | 10+ лет | 350-600k | Технические лиды |

## Правила分类

### Каждая вакансия должна быть отнесена к уровню на основе:
1. **Требуемого опыта** в описании вакансии
2. **Зарплатного диапазона**
3. **Требований к навыкам**

### Исключения из правил:
- Если вакансия указывает "от 1 года", но требует опыт с enterprise-системами → **Middle+**
- Если вакансия указывает "3-6 лет", но требует опытLeadership → **Senior**
- Если вакансия не указывает опыт, но требует архитектурные навыки → **Senior**

## Шаблоны для不同 уровней

### Junior (0-1 год)
- **Резюме:** Resume v0 — Junior React
- **Сопроводительное:** Junior Cover Letter Template
- **Фильтры:** experience=between0And1, salary=80000-150000

### Middle (1-3 года)
- **Резюме:** Resume v1 — Middle React
- **Сопроводительное:** Middle Cover Letter Template
- **Фильтры:** experience=between1And3, salary=120000-200000

### Middle+ (3-6 лет)
- **Резюме:** Resume v2 — Middle+ React
- **Сопроводительное:** Middle+ Cover Letter Template
- **Фильтры:** experience=between3And6, salary=180000-300000

### Senior (6+ лет)
- **Резюме:** Resume v3 — Senior React
- **Сопроводительное:** Senior Cover Letter Template
- **Фильтры:** experience=moreThan6, salary=250000-400000

### Lead/Principal (10+ лет)
- **Резюме:** Resume v4 — Lead React
- **Сопроводительное:** Lead Cover Letter Template
- **Фильтры:** experience=moreThan6, salary=350000-600000

## Процесс分类 вакансий

1. **Собрать вакансии** без фильтра по опыту
2. **Определить уровень** на основе требований
3. **Сохранить в соответствующий раздел**
4. **Применить шаблон** резюме и сопроводительного
