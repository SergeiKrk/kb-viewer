## Правила HH.ru

- **Ограничение на профессии**: hh.ru не позволяет создавать резюме для одной и той же профессии. Для создания tailored резюме под конкретные вакансии необходимо вводить кастомные названия профессий в поле "Профессия" на этапе создания резюме.
  - Примеры: "Front Разработчик - React JS", "Middle Frontend (React/TS, FinTech)", "Frontend (React) разработчик"
  - Названия берутся из `[[Jobs/Tailored Resumes — Middle Tier]]`
- **Work format через API**: UI dropdown для формата работы НЕ обновляет React state. Обязательно устанавливать `workFormats` через API (`POST /applicant/resume/edit`)
- **Modal overlays**: При клике через Playwright перехватывают pointer events. Удалять `document.querySelectorAll('[data-qa="modal-overlay"]').forEach(el => el.remove())` перед каждым кликом
- **Profiession suggestions**: Радиокнопки профессий не кликаются (overlay). Использовать input `[data-qa="resume-profile-position-input"]` и выбирать из suggestions
- **Публикация**: Резюме не публикуется через API. Нужно пройти wizard публикации (5 кликов "Сохранить и продолжить")
- **Проверка сообщений**: После каждого действия (отклик, анализ, любое изменение) проверять страницу откликов `https://ulyanovsk.hh.ru/applicant/negotiations` на наличие новых сообщений от работодателей. При обнаружении — немедленно оповестить пользователя.
