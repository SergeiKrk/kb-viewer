# Отклик на вакансию на HH.ru

_Оптимизированный процесс на основе реального опыта (2026-06-04)_

## Цель

Отправить отклик на вакансию с правильным резюме и сопроводительным письмом.

## Уровни опыта

См. [[Jobs/Experience Levels]] для分类 вакансий по уровням:
- **Junior** (0-1 год): Resume v0, Junior Cover Letter
- **Middle** (1-3 года): Resume v1, Middle Cover Letter
- **Middle+** (3-6 лет): Resume v2, Middle+ Cover Letter
- **Senior** (6+ лет): Resume v3, Senior Cover Letter
- **Lead/Principal** (10+ лет): Resume v4, Lead Cover Letter

## Предусловия

- Авторизован на hh.ru
- Есть опубликованное резюме (см. [[Instructions/Создание tailored резюме]])
- Есть сопроводительное письмо (см. `[[Jobs/Cover Letters — Middle Tier]]`)
- Знаем ID вакансии и ID резюме
- Определили уровень вакансии (см. [[Jobs/Experience Levels]])

## Алгоритм (4 этапа)

### Этап 1: Навигация к вакансии

**URL:** `https://hh.ru/vacancy/{VACANCY_ID}`

1. Открыть страницу вакансии
2. Дождаться загрузки (3 сек)
3. Удалить modal overlays: `document.querySelectorAll('[data-qa="modal-overlay"]').forEach(el => el.remove())`

### Этап 2: Начало отклика

1. Нажать **"Откликнуться"** кнопку
2. Дождаться появления формы отклика (3 сек)

### Этап 3: Выбор резюме

1. Найти dropdown выбора резюме
2. Выбрать резюме по заголовку (точное совпадение)
3. Если резюме не отображается — проверить опубликовано ли оно

### Этап 4: Вставка сопроводительного письма

1. Найти textarea для сопроводительного письма
2. Очистить поле
3. Вставить текст письма
4. Нажать **"Отправить отклик"**

### Этап 5: Проверка

1. Дождаться ответа сервера
2. Проверить сообщение об успешной отправке
3. Записать в лог: ID вакансии, ID резюме, статус

## Шаблон скрипта

```javascript
async function respondToVacancy(page, vacancyId, resumeId, coverLetter) {
  // Этап 1: Навигация
  await page.goto(`https://hh.ru/vacancy/${vacancyId}`);
  await page.waitForTimeout(3000);
  
  // Удалить overlays
  await page.evaluate(() => {
    document.querySelectorAll('[data-qa="modal-overlay"]').forEach(el => el.remove());
  });
  
  // Этап 2: Начало отклика
  const applyButton = page.locator('[data-qa="vacancy-response-link"]');
  await applyButton.click({ force: true });
  await page.waitForTimeout(3000);
  
  // Этап 3: Выбор резюме (если нужно)
  // Форма может автоматически выбрать последнее опубликованное резюме
  // Проверить и выбрать правильное при необходимости
  
  // Этап 4: Вставка письма
  const textarea = page.locator('[data-qa="vacancy-response-letter-input"]');
  await textarea.fill(coverLetter);
  
  // Этап 5: Отправка
  const submitButton = page.locator('[data-qa="vacancy-response-submit"]');
  await submitButton.click({ force: true });
  
  await page.waitForTimeout(3000);
  
  // Проверка успеха
  const success = await page.evaluate(() => {
    return document.body.textContent.includes('Отклик отправлен') ||
           document.body.textContent.includes('Вы уже откликнулись');
  });
  
  return success;
}
```

## Рабочий процесс (проверено на практике)

### Шаг 1: Найти employer ID
```javascript
const employerId = await page.evaluate(() => {
  const applyLink = document.querySelector('[data-qa="vacancy-response-link-top"]');
  const href = applyLink?.getAttribute('href');
  const match = href?.match(/employerId=(\d+)/);
  return match ? match[1] : null;
});
```

### Шаг 2: Перейти на страницу отклика
```
https://hh.ru/applicant/vacancy_response?vacancyId={VACANCY_ID}&employerId={EMPLOYER_ID}&hhtmFrom=vacancy
```

### Шаг 3: Раскрыть поле ввода письма
```javascript
await page.click('[data-qa="vacancy-response-letter-toggle"]');
```

### Шаг 4: Ввести письмо и отправить
```javascript
await page.fill('[data-qa="vacancy-response-popup-form-letter-input"]', coverLetter);
await page.click('[data-qa="vacancy-response-submit-popup"]');
```

### Шаг 5: Проверить результат
```javascript
// После отправки страница перенаправляется на страницу вакансии
// Проверяем наличие кнопки "Отклик другим резюме" = успешно
const applied = await page.evaluate(() => {
  return document.querySelector('[data-qa="vacancy-response-link-top-again"]') !== null;
});
```

## Известные проблемы

| Проблема | Решение |
|----------|---------|
| Overlay блокирует кнопку "Откликнуться" | Удалять `[data-qa="modal-overlay"]` перед кликом |
| Резюме не отображается в dropdown | Проверить опубликовано ли резюме |
| Лимит символов в сопроводительном | Сокращать письмо до 2000 символов |
| Уже откликнулись на вакансию | Проверить сообщение "Вы уже откликнулись" |
| Вакансия в архиве | Проверить статус вакансии перед откликом |
| API возвращает 403 | Использовать UI для отправки, не API |
| Форма не находит textarea | Кликнуть на "Добавить" для раскрытия поля ввода |

## Чек-лист перед откликом

- [ ] Резюме опубликовано
- [ ] Заголовок резюме совпадает с вакансией
- [ ] Сопроводительное письмо содержит ключевые требования вакансии
- [ ] Указан стек (если требует вакансия, как #34 TOP HR)
- [ ] Указана самооценка (если требует вакансия, как #36 Литмаркет)
- [ ] Проверить статус вакансии (не в архиве)

## Важное замечание о выборе резюме

Форма отклика автоматически выбирает **последнее опубликованное резюме**. Если нужно отправить конкретное резюме, необходимо:

1. Перед откликом поднять нужное резюме в списке (нажать "Поднять")
2. Или использовать "Отклик другим резюме" после первого отклика

В текущем процессе мы отправляли отклики с резюме, которые были опубликованы последними:
- #33 ФГАНУ ЦИТ: Frontend-разработчик (React) — не то резюме (нужно было Front Разработчик - React JS)
- #34 TOP HR: Frontend-разработчик (React) — не то резюме (нужно было Middle Frontend-разработчик (React / TypeScript))
- #36 Литмаркет: Frontend-разработчик (React) — не то резюме (нужно было Middle Frontend-разработчик (React))
- #37 Триада: Frontend-разработчик (React) — подходит

**Рекомендация:** Перед откликом убедиться, что нужное резюме является активным (последним опубликованным).
