## Детальный анализ активных каналов

### @cheerful_wino — «Самогонщики» 🥇
- **Тема:** юмористический блог «весёлого алкаша»
- **Формат:** текст + картинка, истории из жизни, тосты
- **Частота:** 2-3 поста в день
- **Вовлечение:** 9-60 репостов
- **Монетизация:** реклама «Самогонщики в MAX»
- **Связи:** чат @alkoclab
- **Пример поста:** «обзор 10-дневного курса по выходу из запоя»
- **Урок для нас:** юмор + личный опыт работают лучше инструкций. Самоирония — ключ к аудитории.

### @c2h5oh_channel — «Самогонщики C2H5-OH» 🥇
- **Тема:** статьи, рецепты, реальный опыт + сайт c2h5-oh.ru
- **Экосистема:** сайт → канал → чат → бот (@Samogon966_bot)
- **Формат:** вопросы-ответы, статьи, репосты с сайта
- **Просмотры:** 378-570
- **Урок для нас:** ЭТО ПРЯМОЙ АНАЛОГ нашей модели! Сайт + канал + чат + бот. Делаем так же для samogoncalc.ru.

### @rdshopru — «Русская Дымка» 🥈
- **Тема:** самогоноварение + пивоварение + консервирование + копчение
- **Магазин:** rdshop.ru — реальный бизнес!
- **Формат:** видео с ректификацией, обзоры оборудования, статьи
- **Просмотры:** 93-889
- **Урок для нас:** магазин использует канал для контент-маркетинга. Мы можем так же: калькуляторы → статьи → партнёрские ссылки.

### @mirbeer_ru — «МирБир» 🥈
- **Тема:** пивоварение + самогоноварение + виноделие + кулинария
- **Магазин:** mirbeer.ru
- **Формат:** анонсы фестивалей, новости индустрии
- **Просмотры:** 361-389
- **Пример поста:** анонс фестиваля «Формула Рома» 4 июля в Москве
- **Урок:** событийный контент + партнёрства с фестивалями

### @moonshinediarysu — «ДНЕВНИКИ САМОГОНЩИКА» 🥉
- **Тема:** рецепты настоек/ликеров/наливок + продажа оборудования
- **Формат:** реклама дубовых кадок/бочек с ценами
- **Просмотры:** 62-240
- **Урок:** рецепты как контент-магнит → продажа оборудования. Нам: рецепты → партнёрские ссылки.
