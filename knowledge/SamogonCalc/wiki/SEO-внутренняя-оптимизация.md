# SEO: Внутренняя оптимизация для Google

**Дата:** 23 июня 2026
**Сайт:** samogoncalc.ru (Astro, статика)
**Статус:** 🟢 завершено (01.07.2026)

---

## 🔴 КРИТИЧЕСКИЕ (немедленно)

### 1. lang="en" → "ru"
- **Где:** `<html lang="en">` на всех страницах
- **Почему:** Google использует lang для определения языка. Сейчас сайт определяется как английский — минус к ранжированию в ру-сегменте
- **Исправление:** в `BaseLayout.astro` заменить `lang="en"` на `lang="ru"`
- **Статус:** ✅

### 2. Meta description — расширить
- **Где:** все страницы
- **Сейчас:** description = H1-заголовок (~50–70 символов)
- **Нужно:** 140–160 символов, включая ключевые слова и CTA
- **Исправление:** в frontmatter MDX добавить `description:` длиннее, в шаблоне брать из frontmatter или генерировать из первых 160 символов контента
- **Статус:** ✅

### 3. 301 редиректы со старых URL
- **Проблема:** старые URL (`/razbavleniya-vodoj/`, `/drobnoj-peregonki/` и др.) → 404
- **Потеря:** весь накопленный ссылочный вес и позиции по этим URL
- **Исправление:** в `.htaccess` или в конфиге jino добавить 301 редиректы:
  - `/razbavleniya-vodoj/` → `/kalkulyator-razbavleniya-samogona-vodoj/`
  - `/drobnoj-peregonki/` → `/kalkulyator-drobnoj-peregonki/`
  - `/otbor-golov/` → `/kalkulyator-otbor-golov/`
  - ... и так для всех 12 калькуляторов
- **Статус:** ✅

## 🟡 ВАЖНЫЕ (на этой неделе)

### 4. Schema.org структурированные данные
- **Сейчас:** нет вообще
- **Нужно добавить:**
  - **BreadcrumbList** — на всех страницах (хлебные крошки уже есть визуально)
  - **FAQ** — на страницах с аккордеоном FAQ (3 калькулятора)
  - **HowTo** — на страницах с пошаговыми инструкциями
  - **WebApplication** — на страницах калькуляторов (тип: калькулятор, описание функций)
  - **Organization** — на главной (лого, соцсети, контакты)
- **Исправление:** создать компоненты Astro для каждого типа Schema
- **Статус:** ✅

### 5. Sitemap — улучшить
- **Сейчас:** `sitemap-0.xml` есть, но без `<lastmod>`, `<priority>`, `<changefreq>`
- **Нужно:** 
  - Добавить `lastmod` (дата последней сборки)
  - Расставить `priority`: главная 1.0, калькуляторы 0.8, рецепты 0.6, about 0.3
  - Добавить `changefreq`: monthly для калькуляторов, weekly для рецептов
- **Исправление:** дополнить генерацию sitemap в `astro.config.mjs` или скриптом после сборки
- **Статус:** ✅

### 6. Title — добавить бренд
- **Сейчас:** `Калькулятор разбавления самогона и спирта`
- **Лучше:** `Калькулятор разбавления самогона водой | SamogonCalc`
- **Исправление:** в BaseLayout.astro: `{title} | SamogonCalc`
- **Статус:** ✅

### 7. Внутренняя перелинковка
- **Сейчас:** только хлебные крошки и список на главной
- **Нужно:**
  - В конце каждого калькулятора — блок «Связанные калькуляторы» (3–4 ссылки)
  - В статьях рецептов — ссылки на релевантные калькуляторы
  - На странице «О проекте» — ссылки на топ-калькуляторы
- **Статус:** ✅

### 8. Изображения: srcset + WebP + размеры
- **Сейчас:** WebP уже генерируется Astro, но:
  - Нет `srcset` для разных разрешений
  - Нет явных `width`/`height` на всех img
  - Нет `loading="lazy"` на изображениях вне viewport
- **Исправление:** пройти по всем `<img>`, добавить атрибуты
- **Статус:** ✅

## 🟢 ЖЕЛАТЕЛЬНЫЕ (следующая неделя)

### 9. Кэширование (Cache-Control)
- **Сейчас:** нет заголовков кэширования
- **Нужно:** в `.htaccess`:
  - Статика (`_astro/*`): `max-age=31536000, immutable`
  - HTML: `max-age=3600, must-revalidate`
  - Sitemap: `max-age=86400`
- **Статус:** ✅

### 10. Open Graph — дополнить
- **Сейчас:** og:title, og:description, og:image, og:type — есть
- **Не хватает:** og:locale (ru_RU), og:site_name, twitter:card
- **Статус:** ✅

### 11. Ссылки на соцсети — nofollow
- **Где:** блок «Репостни меня» (VK, Telegram, Viber, WhatsApp, FB, Twitter)
- **Проблема:** ссылки без `rel="nofollow noopener"` — утекает ссылочный вес
- **Исправление:** добавить `rel="nofollow noopener noreferrer"`
- **Статус:** ✅

### 12. Страница 404 — улучшить
- **Сейчас:** кастомная 404 есть
- **Нужно:** добавить на 404 список популярных калькуляторов (ссылки), поиск pagefind
- **Статус:** ✅

### 13. Скорость загрузки (Core Web Vitals)
- **Сейчас:** 0.34с, 170KB — хорошо
- **Проверить:** LCP (основной контент), CLS (сдвиги), INP (интерактивность)
- **Оптимизировать:**
  - Шрифты: предзагрузка critical-subset
  - CSS: удалить неиспользуемые стили DaisyUI/Tailwind
  - JS: отложить загрузку pagefind, theme-toggle
- **Статус:** ✅
