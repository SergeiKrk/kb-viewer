# Критерии отбора бизнес-идей

## Первичный фильтр (быстрый отсев)

- [ ] Понятна ли проблема? (можем описать её двумя предложениями)
- [ ] Есть ли хотя бы 1000 человек с этой проблемой?
- [ ] Готовы ли они платить за решение? (хотя бы косвенные признаки)
- [ ] Можем ли мы проверить гипотезу за 2 недели и $100?
- [ ] Есть ли у нас или в доступе нужные компетенции?

## ТРИЗ-фильтр

- [ ] Сформулировано ли противоречие? (нет ТП/ФП — нет изобретательской задачи)
- [ ] Сформулирован ли ИКР?
- [ ] Насколько решение приближается к ИКР? (шкала 1–10)

## Бизнес-фильтр

- [ ] Размер рынка (TAM/SAM/SOM) — хотя бы порядок
- [ ] Маржинальность (грубая прикидка)
- [ ] Конкурентный ландшафт (красный/голубой океан?)
- [ ] Регуляторные риски
- [ ] Скорость выхода на самоокупаемость

## Оценка по шкале (1–5)

| Критерий | Вес |
|---|---|
| Острота проблемы | 3 |
| Размер рынка | 2 |
| Конкурентное преимущество | 3 |
| Простота проверки | 2 |
| Масштабируемость | 2 |
| Соответствие компетенциям | 1 |
| ИКР-близость (ТРИЗ) | 2 |

**Порог для продолжения:** ≥ 45 баллов из 75
