# Приёмы профессионального самогонщика

Извлечено из анализа топовых каналов Дзена, Telegram и YouTube.

## 1. Контент-стратегия

### Правило 60/30/10
- **60%** — практическая ценность (рецепты, инструкции, обзоры оборудования)
- **30%** — личный опыт и истории (эксперименты, провалы, успехи)
- **10%** — развлекательное (юмор, мемы, байки)

### Типы постов-лидеров по вовлечению
1. Рецепт с пошаговыми фото и таблицей ингредиентов
2. Сравнение «до/после» (очистка углём, выдержка в бочке)
3. Разбор ошибок: «почему брага не забродила»
4. Обзор оборудования с личным опытом использования
5. Эксперимент: «что будет если добавить X в брагу»
6. Историческая справка + рецепт (культурный контекст)
7. Калькулятор + пояснение как считать

## 2. Технические приёмы ведения канала

### Заголовки
- Вопрос: «Почему брага горчит?»
- Цифра: «3 ошибки новичка при первой перегонке»
- Контраст: «Самогон за 300 ₽ vs за 3 000 ₽ — есть ли разница?»
- Личный вызов: «Я перегнал брагу на дрожжах за 50 ₽. Результат:»

### Визуал
- Первое фото — самое эффектное (готовый продукт в красивом бокале)
- Промежуточные фото процесса (брага в ёмкости, аппарат в работе, струя дистиллята)
- Финальное фото — результат на столе
- Видео процесса ценится выше фото

### Вовлечение
- Заканчивать пост вопросом к читателям
- Проводить голосования: «На чём ставите брагу? Сахар / Зерно / Фрукты»
- Просить поделиться опытом в комментариях
- Создать чат для общения подписчиков

### Регулярность
- Минимум: 3 поста в неделю
- Оптимум: 1 пост в день
- Лучшее время: вечер (19:00–22:00 МСК), выходные

## 3. Монетизация канала

### Прямые методы
1. Партнёрские ссылки (Яндекс.Маркет, Ozon, WB) — основной канал
2. Реклама оборудования/ингредиентов (Kolba, Русская Дымка, Геликон)
3. Собственные товары (мерч, наборы ингредиентов)

### Косвенные методы
1. Переходы на сайт с калькуляторами → партнёрские ссылки
2. Донаты (бусти, sponsor.ru)
3. Платный контент (эксклюзивные рецепты, гайды)

## 4. Специализация и УТП

### Варианты нишевания
- **По сырью:** зерновые / фруктовые / сахарные / экзотические браги
- **По продукту:** настойки / дистилляты / ликёры / пиво
- **По методу:** классическая дистилляция / ректификация / выдержка в бочках
- **По аудитории:** новички / продвинутые / профи
- **По подходу:** наука (химия, хроматография) / традиция (дедовские методы) / DIY (самодельное оборудование)

### УТП SamogonCalc
- **Калькуляторы** — уникальный инструмент, которого нет у конкурентов
- **«Считаем, а не гадаем»** — позиционирование через точность
- **ТРИЗ-подход** — системное мышление о процессе

## 5. Кросс-платформенное продвижение

### Схема «Сайт → Telegram → Dzen → Pikabu»
```
Сайт (samogoncalc.ru)
  └─ Калькуляторы + статьи
     └─ CTA: «Подпишись на Telegram @samogonco»
        └─ Telegram: рецепты, анонсы, сообщество
           └─ CTA: «Читай полную версию на сайте»
              └─ Dzen: SEO-статьи, обзоры
                 └─ Pikabu: вирусные посты, личные истории
```

### Платформенная специфика
- **Сайт:** калькуляторы, SEO-статьи, база знаний
- **Telegram:** оперативный контент, рецепты, сообщество, опросы
- **Dzen:** длинные статьи, обзоры, рецепты с фото
- **Pikabu:** юмор, байки, неожиданные результаты, «горячие» темы
- **YouTube/Rutube:** видео процессов, обзоры оборудования
