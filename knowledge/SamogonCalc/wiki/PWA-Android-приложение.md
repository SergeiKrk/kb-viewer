# Анализ Android-приложения / PWA для samogoncalc

**Дата:** 23 июня 2026

## Суть

Рассматривается создание мобильного двойника samogoncalc.ru — либо нативного Android-приложения, либо PWA.

## Плюсы

| Фактор | Описание |
|---|---|
| **Push-уведомления** | Прямой канал: новые рецепты, обновления. Конверсия в Telegram с пуша в 3–5× выше, чем с веба |
| **Новая аудитория** | Play Market как отдельный источник трафика. Запросы «калькулятор самогонщика» гуглят и в маркете |
| **AdMob-монетизация** | Баннеры/interstitial без ограничений РСЯ (алкогольная ниша не блокируется в AdMob). CPM в РФ: $0.5–2 |
| **Офлайн-режим** | Калькуляторы работают без интернета — плюс для дач/деревень |
| **Встроенные покупки** | Платные гайды, премиум-рецепты — покупка в 1 клик без внешних платёжных страниц |

## Риски

| Фактор | Описание |
|---|---|
| **Google Play и алкоголь** | Play Market ограничивает приложения, «продвигающие алкоголь». Калькулятор как сервисная утилита скорее пройдёт. Рецепты настоек — под вопросом |
| **Каннибализация трафика** | Часть веб-трафика уйдёт в приложение. Если в приложении больше рекламы — плюс, а не минус |
| **Двойная поддержка** | Два кодовых базы = двойная работа. Решается через PWA |
| **AdMob-фильтрация** | AdMob тоже фильтрует контент. Может ограничить показы. Альтернативы: MyTarget, AdFox |

## Рекомендованный подход: PWA

**Не писать нативное Android-приложение, а сделать PWA (Progressive Web App):**

- Один `manifest.json` + Service Worker — тот же код, что и сайт
- Устанавливается на Android с иконкой на рабочем столе
- Работает офлайн (все калькуляторы на JS)
- Не требует модерации Google Play
- Можно завернуть в Trusted Web Activity для публикации в Play Market
- **Бесплатно** — не нужно нанимать Android-разработчика

## Прогноз влияния на монетизацию

| Канал | Сейчас | С PWA/приложением |
|---|---|---|
| Веб-трафик | 100% | 70–80% |
| App-трафик | 0 | +20–30% новых |
| AdLook (веб) | X ₽ | 0.7X |
| AdMob (app) | 0 | +Y ₽ (новый канал) |
| Партнёрские ссылки | Z ₽ | ~Z ₽ |
| Telegram-подписки | N/мес | +30–50% N |
| Платные гайды | 0 | +W ₽ (встроенные покупки) |

**Итог:** прирост 20–40% к монетизации. Основной риск — модерация Play Market.

## План внедрения (на будущее)

1. Добавить `manifest.json` в astroSam — 30 минут
2. Service Worker для офлайн-калькуляторов — 1 час
3. Протестировать PWA на своём Android
4. Если заходит — обернуть в Trusted Web Activity → Play Market
