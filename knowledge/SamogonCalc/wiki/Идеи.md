# 10 бизнес-идей (Раунд 1)

Сгенерировано: 22 июня 2026
Метод: ТРИЗ + анализ ресурсов + партизанский маркетинг

---

## Идея 1. Монетизация калькулятора самогонщика
**Суть:** Встроить партнёрские ссылки и рекламные блоки в существующий калькулятор. Партнёрки: магазины самогонных аппаратов, ингредиентов (дрожжи, солод), книг и курсов.
**ТРИЗ-приём:** #24 Посредник — трафик уже есть, добавляем посредника (партнёрскую ссылку) между пользователем и доходом.
**Ресурсы:** готовый сайт, трафик 300/сутки.
**Запуск:** 1 неделя.
**Риски:** низкий средний чек, сезонность.

## Идея 2. Оживление Telegram-канала + платный контент
**Суть:** Начать регулярно постить в канал (рецепты, лайфхаки, обзоры). Монетизация: партнёрские ссылки + платный мини-курс/гайд «100 рецептов настоек» или премиум-доступ к расширенному калькулятору.
**ТРИЗ-приём:** #15 Динамичность — адаптация контента под сезон (летом — ягодные настойки, зимой — крепкие напитки).
**Ресурсы:** канал 1000 подписчиков, калькулятор как лид-магнит.
**Запуск:** 2 недели на оживление, 1 месяц на продукт.
**Риски:** долгое оживление мёртвой аудитории.

## Идея 3. Сеть SEO-лендингов под товарные ключи
**Суть:** Создать 10–20 микро-сайтов (или страниц на одном сайте) под конкретные товарные ключи: «самогонный аппарат Люкссталь отзывы», «дрожжи турбо купить» и т.д. Каждая страница — обзор + партнёрская ссылка. Трафик через SEO.
**ТРИЗ-приём:** #1 Дробление — вместо одного большого сайта сеть микро-лендингов.
**Ресурсы:** навыки SEO и веб-разработки, LLM для контента.
**Запуск:** 1 месяц на первые лендинги.
**Риски:** санкции поисковиков за «партнёрские doorway», медленный рост SEO.

## Идея 4. LLM-контент-фабрика для Дзена
**Суть:** Генерировать через LLM качественные статьи на несколько тем (самогоноварение, сад/огород, обустройство дома). Публиковать на Дзене и своём сайте. Монетизация: встроенная реклама Дзена + партнёрские ссылки + перелив трафика на основной сайт.
**ТРИЗ-приём:** #25 Самообслуживание — LLM генерирует контент, система сама наполняется.
**Ресурсы:** LLM-навыки, свободное время.
**Запуск:** 2 недели до первых публикаций.
**Риски:** алгоритмы Дзена непредсказуемы, пессимизация за «ИИ-контент».

## Идея 5. Платный гайд/курс по самогоноварению
**Суть:** Создать инфопродукт: «Полный гайд начинающего самогонщика» — рецепты, таблицы, калькуляторы, видео. Цена 990–1990 ₽. Трафик через калькулятор + Telegram + SEO-статьи.
**ТРИЗ-приём:** #13 Наоборот — не продавать товары, продавать знания.
**Ресурсы:** калькулятор как лид-магнит, аудитория в нише.
**Запуск:** 1–2 месяца на создание продукта.
**Риски:** пиратство, малый рынок платных инфопродуктов в нише.

## Идея 6. Агрегатор-каталог оборудования с рейтингами
**Суть:** Сайт-каталог самогонных аппаратов и аксессуаров: сравнение моделей, рейтинги, отзывы, цены. Трафик через SEO. Доход — партнёрские ссылки + платное размещение для производителей.
**ТРИЗ-приём:** #5 Объединение — собрать разрозненные товары в единый каталог.
**Ресурсы:** навыки веб-разработки и SEO, LLM для обзоров.
**Запуск:** 2–3 месяца.
**Риски:** конкуренция с маркетплейсами (Ozon, WB), доверие к отзывам.

## Идея 7. SEO-контент-услуги для малого бизнеса
**Суть:** Услуга: «SEO-аудит + контент-план + 10 статей под ключ» для малых бизнесов. Использовать LLM для генерации статей, свои SEO-навыки для стратегии. Цена: 20 000–50 000 ₽ за пакет.
**ТРИЗ-приём:** Перенос ресурса (навыки SEO + LLM) в надсистему (рынок услуг).
**Ресурсы:** SEO + LLM-навыки.
**Запуск:** 1 месяц на упаковку услуги.
**Риски:** высокая конкуренция на рынке SEO-услуг, работа с клиентами = занятость.

## Идея 8. Сайт по нише «Дом, сад, огород»
**Суть:** Создать сайт/блог по уходу за садом, огородом, растениями. Статьи через LLM, продвижение через Дзен и SEO. Монетизация: партнёрские ссылки (средства защиты растений, удобрения, садовый инструмент) + AdSense. Не зависеть от одного партнёра.
**ТРИЗ-приём:** #15 Динамичность — контент под сезон (весна — посадка, лето — полив, осень — обрезка).
**Ресурсы:** понимание ниши (смежная с предложением партнёра), LLM.
**Запуск:** 1 месяц до первых статей.
**Риски:** сезонность трафика, медленный рост SEO.

## Идея 9. Сеть микро-калькуляторов (SaaS-сетка)
**Суть:** Создать ещё 5–10 калькуляторов в разных нишах по образцу калькулятора самогонщика: калькулятор ремонта, кулинарный калькулятор, калькулятор посадок (огород), калькулятор материалов для стройки. Монетизация: партнёрские ссылки + реклама.
**ТРИЗ-приём:** #1 Дробление + #15 Динамичность — тиражирование успешной модели в другие ниши.
**Ресурсы:** шаблон калькулятора, LLM, навыки веб-разработки.
**Запуск:** 1 калькулятор в месяц.
**Риски:** конкуренция с крупными сервисами, поддержка каждого калькулятора.

## Идея 10. База знаний / Вики по хобби-ницам
**Суть:** Создавать структурированные базы знаний (наподобие IdeaResearch) по популярным хобби: самогоноварение, садоводство, рыбалка, ремонт. Каждая — сайт с SEO-оптимизированными статьями, навигацией, партнёрскими ссылками. Монетизация: партнёрки + платный премиум-контент (закрытые гайды).
**ТРИЗ-приём:** #5 Объединение — собрать разрозненные знания в структуру.
**Ресурсы:** опыт создания баз знаний (LLM Wiki), LLM, SEO.
**Запуск:** 2–3 месяца на первую базу.
**Риски:** долгий запуск, много контента для наполнения.
