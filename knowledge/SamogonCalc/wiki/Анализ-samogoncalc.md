## ТРИЗ-анализ текущего состояния

### Системный анализ

**Что есть (компоненты системы):**
- Двигатель: SEO-трафик (300 чел/сут)
- Трансмиссия: 12 калькуляторов + 28 рецептов = полезный контент
- Рабочий орган: рекламные блоки RLA + AdLook
- Управление: отсутствует (нет аналитики конверсий, A/B-тестов)

**Закон полноты частей:** система НЕ полна — компонент «управление» отсутствует.

### Противоречия

**ТП-1:** Чтобы увеличить доход, нужно больше рекламы. Но больше рекламы ухудшает UX и может снизить трафик.
→ **Решение:** не больше рекламы, а замена на партнёрские ссылки с более высоким ECPC + нативные интеграции.

**ТП-2:** Чтобы улучшить SEO, нужен текстовый контент. Но основная ценность — в калькуляторах (инструмент), а не в тексте.
→ **Решение:** добавить пояснительный контент КАК ЧАСТЬ калькулятора (HowTo schema, пояснения полей, FAQ).

**ФП:** Сайт должен быть простым (быстрый расчёт) И содержательным (SEO + доверие).
→ **Решение:** базовый интерфейс без изменений + раскрывающиеся блоки с пояснениями, которые не мешают расчёту.
