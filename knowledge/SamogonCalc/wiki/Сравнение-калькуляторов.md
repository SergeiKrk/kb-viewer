## Наше преимущество

### Что у нас есть уникального
1. **12 отдельных калькуляторов** — каждый со своим URL, Title, Description (SEO!)
2. **Виджеты «Что понадобится»** — контекстная монетизация через партнёрки
3. **PWA** — офлайн-доступ, установка на телефон как приложение
4. **Адаптивный дизайн** — работает на мобильных
5. **Визуализация** — схемы, графики
6. **Schema.org разметка** — сниппеты в поиске
7. **Скорость** — Astro SSG, мгновенная загрузка

### Какие калькуляторы можно добавить

- [ ] **Замена сахара глюкозой/фруктозой** — востребовано (сахар дорожает)
- [ ] **Кислотность сусла** — для продвинутых винокуров
- [ ] **Коррекция ареометра по температуре** — полезно и просто реализовать
- [ ] **Дистилляция до воды** — когда остановить перегонку
- [ ] **Выход спирта из разного сырья** — яблоки, зерно, виноград, свёкла
- [ ] **Калькулятор второй перегонки** — дробная дистилляция
- [ ] **Купажирование нескольких фракций** — расширенная версия смешивания
- [ ] **Калькулятор настаивания** — расчёт ингредиентов и времени

### Приоритет (мнение):
1. Калькулятор второй перегонки (высокий спрос)
2. Замена сахара на глюкозу/фруктозу (уникально)
3. Коррекция ареометра (просто, полезно)
4. Выход спирта из разного сырья (SEO-магнит)
