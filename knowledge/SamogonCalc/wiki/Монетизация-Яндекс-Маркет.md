## 1. Реферальная программа Яндекс.Маркета — условия

### Как подключиться
1. **Путь А — напрямую:** `https://partner.market.yandex.ru/` → регистрация вебмастера
2. **Путь Б — через Admitad:** Яндекс.Маркет есть в Admitad как рекламодатель (оффер 100500+). Проще управлять через единый интерфейс.

### Условия (типовые для товарных партнёрок)
| Параметр | Значение |
|----------|----------|
| Комиссия | 0.5%–3% от стоимости заказа (зависит от категории) |
| Cookie-окно | 30 дней |
| Модель | CPS (cost per sale) — оплата за подтверждённый заказ |
| Минимальная выплата | 3 000 ₽ |
| Deep-link | Да — можно вести на конкретный товар |

### Категории, релевантные для самогоноварения
- **Товары для дома** → Товары для кухни → Домашнее виноделие и самогоноварение
- **Дача и сад** → Инвентарь для заготовок
- **Бытовая химия** → Ингредиенты (дрожжи, ферменты, уголь)
- **Посуда** → Стеклянные бутыли, банки, бочки

## 2. ТРИЗ-анализ: почему именно Яндекс.Маркет

### Противоречие (ТП)
**Чтобы** зарабатывать на партнёрках, **нужны** товарные ссылки. **Но** самогоноварение — нишевый товар, конверсия низкая. 
→ **Решение (приём #10 — Предварительное действие):** пользователь приходит на сайт с ПРАКТИЧЕСКОЙ задачей («разбавить самогон», «посчитать головы»). В момент расчёта ему НУЖНЫ инструменты (ареометр, спиртометр, ёмкости). Партнёрская ссылка в этот момент — не реклама, а помощь.

### ИКР монетизации
**Система САМА** определяет, какой инструмент нужен пользователю прямо сейчас (по контексту калькулятора), показывает подборку из 3–5 товаров на Яндекс.Маркете и получает 1–3% от каждой покупки. Пользователь доволен (купил нужное), Сергей получает пассивный доход.

### Закон полноты частей
| Часть системы | Есть? | Что нужно |
|---------------|-------|-----------|
| Двигатель | ✅ Трафик 300 чел/сут | Растёт с SEO |
| Трансмиссия | ❌ | **Создать:** подборки оборудования + реферальные ссылки |
| Рабочий орган | ❌ | **Подключить:** Admitad / Яндекс.Маркет API |
| Управление | ❌ | **Настроить:** UTM-метки, отслеживание конверсий в Метрике |

## 3. Что продавать: карта товаров

### 3.1 Самогонные аппараты (высокий чек: 5 000–50 000 ₽)
- Дистилляторы с сухопарником (базовый сегмент: 5–10К)
- Аппараты с дефлегматором/царгой (средний: 10–25К)
- Ректификационные колонны (профи: 25–50К)
- Комплекты «всё включено»

**Страницы для размещения:** «Калькулятор себестоимости», «Дробная перегонка»

### 3.2 Измерительные приборы (низкий чек: 200–1 500 ₽, высокий объём)
- Ареометры / спиртометры АСП-3
- Виномеры / сахаромеры
- Электронные термометры (щупы, инфракрасные)
- Рефрактометры
- Мерные цилиндры

**Страницы:** «Абсолютный спирт», «Разбавление самогона», «Температура»

### 3.3 Ингредиенты (низкий чек: 100–1 000 ₽, регулярные покупки)
- Спиртовые дрожжи (турбо, винные, универсальные)
- Декстроза (замена сахара)
- Уголь активированный (кокосовый, берёзовый)
- Бентонит (осветление браги)
- Специи и травы для настоек

**Страницы:** «Сахарная брага», «Замена сахара декстрозой», рецепты настоек

### 3.4 Ёмкости и аксессуары (средний чек: 500–5 000 ₽)
- Пластиковые ёмкости для брожения (30–60 л)
- Стеклянные бутыли (10–20 л)
- Дубовые бочки (3–20 л)
- Гидрозатворы, шланги, переходники

**Страницы:** «Выход браги», рецепты

## 4. Архитектура разделов на сайте

### 4.1 Страницы-подборки (новый тип контента)

Создаём раздел `/oborudovanie/` с подборками:

```
/oborudovanie/
  ├── samogonnye-apparaty/       — 5–7 аппаратов со сравнением
  ├── areometry-i-termometry/    — измерительные приборы
  ├── drozhzhi-i-ingridienty/    — дрожжи, декстроза, уголь
  ├── emkosti-i-bochki/          — ёмкости для брожения
  └── nabor-nachinayushego/      — «Стартовый набор самогонщика»
```

### 4.2 Виджет «Что понадобится» на калькуляторах

На каждом калькуляторе — контекстный блок **«🛒 Для этого расчёта понадобится»**:
- Абсолютный спирт → ареометр + мерный цилиндр
- Разбавление → спиртометр + калькулятор пропорций → вода + ёмкость
- Сахарная брага → дрожжи + гидрозатвор + ёмкость
- Дробная перегонка → термометр + дефлегматор

### 4.3 На главной: блок «Рекомендуемое оборудование»

Прямо под калькуляторами — карусель из 4–6 карточек товаров.

## 5. Форматы реферальных ссылок

### Прямые ссылки Яндекс.Маркета
```
https://market.yandex.ru/product--{slug}/{id}?referrer={partner_id}&utm_source=samogoncalc&utm_medium=referral
```

### Через Admitad (рекомендуется)
- Единый личный кабинет
- Deeplink-генератор: вставляешь URL товара → получаешь партнёрскую ссылку
- Статистика кликов и конверсий

### UTM-разметка
Каждая ссылка маркируется:
```
?utm_source=samogoncalc&utm_medium=referral&utm_campaign={calculator_slug}&utm_content={product_position}
```
