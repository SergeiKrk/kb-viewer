## SEO-анализ

### Метаданные
- **Keywords:** отсутствует
- **Description:** заполнен на всех страницах (уникальные тексты для категорий)
- **Canonical:** есть на главной
- **OG-теги:** только `og:type: Article` (ограниченно)
- **Structured Data:** отсутствует (нет JSON-LD разметки)

### Заголовки
- H1 присутствует на всех страницах
- На главной H1 = "Сайт ценителей спиртных напитков" (слабое ключевое соответствие)
- На категориях H1 = название категории

### URL-структура
- Статьи: `/kak-razvesti-spirt-vodoj-v-domashnix-usloviyax.html` (транслит, дескриптивные)
- Категории: `/category/osnovy-samogonovareniya`
- Пагинация: `/category/osnovy-samogonovareniya/page/2`
- Калькуляторы: `/raschet-parametrov-samogonovareniya`

### Техническое
- Yandex Metrika + Yandex Search (виджет в сайдбаре)
- Возрастной попап (18+)
- Cookie-баннер
- Рекламные блоки Яндекс.Директ
- Сайтбар: рубрики (иерархическое меню) + поиск Яндекса

### Ключевые SEO-слабости alcofan (возможности для нас)
1. Нет Schema.org разметки (Article, FAQ, HowTo, BreadcrumbList)
2. Нет meta keywords
3. Нет OpenGraph (только type, без title/description/image)
4. H1 на главной слабый (не содержит «самогоноварение»)
5. Дизайн устаревший, не адаптивный
6. Нет мобильной версии/AMP
7. Нет PWA

## Выводы и возможности

### Что мы можем сделать лучше
1. **Schema.org разметка** — Article, HowTo, FAQ, BreadcrumbList, SoftwareApplication
2. **OpenGraph + Twitter Cards** — полноценные превью для соцсетей
3. **Постраничные калькуляторы** — каждый калькулятор на своей странице со своим Title/Description
4. **Виджеты «Что понадобится»** — контекстная монетизация через партнёрки (у alcofan нет)
5. **PWA** — офлайн-доступ (уже есть!)
6. **Визуализация** — графики, схемы процесса (у alcofan только текст)
7. **Скорость** — Astro + статика быстрее WordPress-блога

### Ключевые темы для покрытия (из анализа alcofan)
- Разбавление спирта (у нас есть калькулятор!) — наша сильная сторона
- Отбор голов и хвостов (у нас есть!)
- Сахарная брага (у нас есть!)
- Вторая перегонка — **можно добавить калькулятор**
- Температура перегонки — уже калькулятор на сайте
- Очистка самогона — **можно добавить статью**
- Рецепты из разного сырья — **можно расширить**

Практически **полный охват всех мыслимых ингредиентов**:

### Ключевые инсайты

1. **Стратегия alcofan:** максимальный охват длинного хвоста через шаблонные статьи
   - Формула: «[Продукт] + [процесс]: [вариации]»
   - Один тип контента × 100+ ингредиентов = сотни страниц

2. **Что у них отсутствует:**
   - ❌ Интерактивные инструменты (кроме одной страницы калькуляторов)
   - ❌ Визуализация процессов (графики, схемы)
   - ❌ Мобильная версия
   - ❌ Персонализация под пользователя
   - ❌ Видео-контент

3. **Наше преимущество:**
   - Мы не можем конкурировать по объёму статей (193 vs наши ~12)
   - Но можем выиграть за счёт: **калькуляторов + визуализации + интерактивности**
   - Стратегия: не «ещё один рецепт самогона из фейхоа», а «калькулятор идеальной браги из любого сырья»

4. **SEO-дыры alcofan (возможности для нас):**
   - «Калькулятор браги из [сырьё]» — у них нет отдельных страниц
   - «Расчёт выхода спирта из [сырьё]» — у них только общая теория
   - «Таблица гидромодулей для разного сырья» — сводные данные
   - «Сравнение дрожжей для браги» — интерактивный выбор

### Что можно позаимствовать
- Офлайн-калькулятор (CalcSam) — идея для нас (PWA частично решает)
- Структура форума — не наш путь, у нас Telegram-сообщество
