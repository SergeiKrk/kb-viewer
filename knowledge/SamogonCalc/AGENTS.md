# SamogonCalc — База знаний для продвижения samogoncalc.ru

## Проект
Развитие, контент-стратегия и монетизация сайта калькуляторов самогонщика samogoncalc.ru.

## Правила работы агента

### Приоритетная методология: ТРИЗ
При анализе проблем, генерации идей и разработке контента агент **обязан** применять инструментарий ТРИЗ:
1. **Выявление противоречий** — технических (ТП), физических (ФП), административных (АП)
2. **Идеальный конечный результат (ИКР)** — формулировка идеального решения
3. **40 изобретательских приёмов**
4. **Вещественно-полевой анализ (веполь)**
5. **АРИЗ** — пошаговая методика

### Направления работы
- SEO-продвижение: ключевые слова, внутренняя оптимизация, ссылочная масса
- Партнёрские ссылки: Яндекс.Маркет, интеграция в калькуляторы и статьи
- Контент: статьи, рецепты, советы по самогоноварению
- Площадки: Telegram @samogonco, Дзен, Пикабу, YouTube
- Монетизация: партнёрки, Telegram-бот, собственные продукты
- Техническое развитие: PWA, скорость загрузки, новые калькуляторы
