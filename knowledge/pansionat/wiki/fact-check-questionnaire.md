## Часть 1. Факт-чекинг текущего макета (18 блоков)

### Блок 1. Hero — цена в H1 + лицензия
- [ ] **Количество постояльцев:** в макете указано «150+». Какая реальная цифра за всё время работы?
- [ ] **Год основания:** в макете «с 2018 года» — верно?
- [ ] **Лицензия Минздрава:** есть ли действующая лицензия? Номер, кем выдана, срок действия?
- [ ] **ИНН:** какой реальный ИНН организации? Подтвердите, что юрлицо зарегистрировано в Ульяновске.

### Блок 2. Чек-лист «Как понять, что пора»
- [ ] **Подтвердите 6 признаков из макета.** Вот они: (1) падения участились, (2) забыл выключить плиту, (3) путает лекарства, (4) не справляется с гигиеной, (5) потеря веса, (6) агрессия/апатия. Какие из них вы считаете главными? Какие нужно добавить или убрать?
- [ ] Есть ли у вас статистика: с какими из этих состояний чаще всего поступают постояльцы?

### Блок 3. Доверие — лицензия, цифры, ИНН
- [ ] Номер лицензии: реальный Л041-...? Или будет получен?
- [ ] Есть ли другие документы/сертификаты, которые можно показать?

### Блок 4. Калькулятор стоимости
- [ ] Готовы ли предоставить сетку цен (город → состояние → тип размещения → цена)?
- [ ] Какие факторы реально влияют на цену?

### Блок 5. Преимущества
- [ ] **«Врач 24/7»** — есть ли врач в штате круглосуточно? Или приходящий?
- [ ] **«5-разовое питание»** — верно? Есть ли диетолог?
- [ ] **«Охрана»** — есть ли охрана? Физическая или пультовая?
- [ ] **«Индивидуальный уход»** — как это организовано? Соотношение персонал/постояльцы?

### Блок 6. Видео-презентация
- [ ] Есть ли готовые видео-материалы? Если нет, готовы ли снимать?
- [ ] Можно ли снимать постояльцев? Есть ли согласия?

### Блок 7. Сравнение «Мы vs серые пансионаты»
- [ ] **«Врач в штате»** — подтверждаете? Сколько врачей?
- [ ] **«5-разовое меню от диетолога»** — есть ли диетолог? Или меню составляется иначе?
- [ ] Есть ли у вас примеры «серых» пансионатов в Ульяновске (без имён) для честного сравнения?

### Блок 8. Распорядок дня
- [ ] Соответствует ли таймлайн 7:30–22:00 реальному распорядку? Поправьте.
- [ ] Выходные/праздники отличаются?

### Блок 9. Условия проживания
- [ ] Какие типы комнат реально есть? 1-2-3 местные? Есть ли люкс?
- [ ] **«Санузел с поручнями»** — во всех комнатах? Или общий?
- [ ] **«Территория для прогулок»** — есть ли огороженная территория? Площадь?

### Блок 10. Сетка заболеваний
- [ ] Какие заболевания из списка реально обслуживаются? (деменция, Альцгеймер, Паркинсон, инсульт, перелом шейки бедра, пролежни)
- [ ] С какими заболеваниями НЕ берёте?
- [ ] Есть ли специализированное оборудование (противопролежневые матрасы, подъёмники)?

### Блок 11. Сиделка или пансионат?
- [ ] **«от 33 000 ₽/мес»** — верная минимальная цена за полный месяц?
- [ ] Актуальна ли цена сиделки «от 45 000 ₽/мес» для Ульяновска?
- [ ] Есть ли у вас программа временного пребывания (передышка для родственников)?

### Блок 12. Отзывы
- [ ] Есть ли реальные отзывы? Сколько? Где собраны (Яндекс, Google, 2ГИС)?
- [ ] Есть ли видеоотзывы?
- [ ] Можно ли публиковать имена/фото?

### Блок 13. Команда + письмо основателя
- [ ] Кто основатель/директор? Готов ли написать личное обращение?
- [ ] Есть ли личная история (почему открыли пансионат)?
- [ ] Фото персонала: сколько человек? Можно ли фотографировать?

### Блок 14. FAQ
- [ ] **Какие вопросы чаще всего задают при первом звонке?** Например: «Какие документы нужны?», «Можно ли приехать на время?», «Что входит в стоимость?» — пришлите свой топ-5 реальных вопросов.
- [ ] Реально ли «приехать с собакой / кошкой»? Есть ли у вас опыт размещения с животными?
- [ ] Есть ли ограничения по срокам: минимальный срок пребывания? Максимальный?

### Блок 15. Квиз «Подбор пансионата»
- [ ] Есть ли различия между филиалами по специализации или условиям? Даже если их 2 — чем один отличается от другого?
- [ ] Какие критерии важны для выбора: район, цена, наличие врача, тип комнат?

### Блок 16. Карта
- [ ] Точные адреса всех филиалов? Напишите в формате: «ул. Примерная, д.1 — филиал такой-то».
- [ ] Есть ли фото каждого филиала снаружи? Если нет — разрешите сделать?

### Блок 17. «Написать директору»
- [ ] Готов ли директор отвечать лично? В какие сроки реально?
- [ ] «В течение 2 часов» — выполнимо?

### Блок 18. Форма + контакты
- [ ] **Номер 8-800:** есть ли? Или только местный?
- [ ] **Email:** info@simbirsk-pansionat.ru — существует? Какой фактический?
- [ ] Соцсети: есть ли страницы? Какие?

## Часть 2. Вопросы по списку жемчужин (20 блоков)

### По жемчужинам российских конкурентов (применимость к «СимбирскЪ»)

- [ ] **Чек-лист «Как понять, что пора»:** Какие признаки вы сами называете родственникам при консультации? В макете 6 признаков: падения, забытая плита, путаница с лекарствами, гигиена, потеря веса, агрессия/апатия. Какие из них совпадают с вашим опытом? Какие нужно добавить?

**Письмо основателя:**
- [ ] Готов ли руководитель к публичному обращению? С фото? С личной историей?

**Калькулятор стоимости:**
- [ ] Готовы ли к прозрачному ценообразованию на сайте? Или цена «по звонку»?

**Сравнение «Мы vs серые пансионаты»:**
- [ ] Какие реальные отличия от конкурентов вы можете подтвердить документально? Не боитесь ли реакции конкурентов на прямое сравнение?

**«Написать директору»:**
- [ ] Готов ли руководитель получать прямые сообщения с сайта?

**Распорядок дня:**
- [ ] Чем ваш распорядок отличается от конкурентов? Уникальные элементы?

**«Сиделка или пансионат?»:**
- [ ] Есть ли у вас данные по стоимости сиделки в Ульяновске? Актуальные?

**Городской селектор:**
- [ ] Этот блок подразумевает филиалы в разных городах. Планируете ли расширение в другие города области (Димитровград, Инза и др.)? Или селектор не актуален и нужно убрать?

**Сетка карточек заболеваний:**
- [ ] По каким заболеваниям у вас есть особая экспертиза? (например, деменция — ваша сильная сторона?)

**Слайдер «Жизнь постояльцев»:**
- [ ] Есть ли фотографии с активностей? Можно ли их публиковать?

### По жемчужинам зарубежных сайтов (можно ли внедрить в «СимбирскЪ»)

**Двойной призыв «Для себя» / «Для близкого»:**
- [ ] Кто чаще обращается: сами пожилые или их родственники? В каком соотношении?

**Навигатор «С чего начать?»:**
- [ ] Какие 3-4 вопроса вам задают при ПЕРВОМ звонке? (это будут карточки навигатора вместо длинного FAQ)

**«История началась с мамы»:**
- [ ] Есть ли личная история основания? Кто был первым постояльцем?

**Профессиональный фильм о пансионате:**
- [ ] Готовы ли инвестировать в видеосъёмку? Бюджет?

**Приложение / Telegram-канал для семьи:**
- [ ] Как сейчас родственники получают информацию о состоянии близкого? (звонки, чаты?) Готовы ли к Telegram-каналу для семей?

**«Нам доверяют X семей»:**
- [ ] Сколько всего постояльцев было за всё время? Точная цифра?

**Тройной призыв + «Карьера у нас»:**
- [ ] Есть ли потребность в персонале? Какие вакансии?

**«Признаны №1 теми, кто важнее всего»:**
- [ ] Есть ли награды, дипломы, благодарственные письма?

**Бренд-философия ухода:**
- [ ] Есть ли у вас своя философия/миссия ухода? Можете сформулировать в 2-3 предложениях?

**Карта филиалов с вместимостью:**
- [ ] Какая вместимость каждого филиала? Количество персонала?
