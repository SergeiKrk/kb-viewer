6|6|## Ключевая идея
7|7|
8|8|Нейросети — это **не просто ещё один классификатор** в арсенале ML-инженера. Это начало фундаментального сдвига в том, **как мы пишем программы**.
9|9|
10|10|> «Software (1.0) is eating the world, and now AI (Software 2.0) is eating software.»

14|14|## Software 1.0 vs Software 2.0
15|15|
16|16|| | **Software 1.0** | **Software 2.0** |
17|17||---|---|---|
18|18|| **Код** | Явные инструкции (Python, C++) | Веса нейросети (миллионы чисел) |
19|19|| **Кто пишет** | Программист | Оптимизация (градиентный спуск) |
20|20|| **Исходники** | .cpp / .py файлы | Датасет + архитектура |
21|21|| **Компиляция** | Компилятор → бинарник | Обучение → готовая сеть |
22|22|| **Отладка** | Дебаггер, точки останова | Добавление примеров в датасет |
23|23|| **Итерация** | Правка кода | Доращивание/чистка данных |
24|24|
25|25|### Аналогия
26|26|- **Software 1.0**: программист → исходный код → компилятор → бинарник → работа
27|27|- **Software 2.0**: датасет + архитектура → обучение (SGD) → веса → работа
28|28|

31|31|## Как это работает
32|32|
33|33|1. **Задаём цель**: «классифицируй эти картинки» или «выиграй в Go»
34|34|2. **Пишем скелет**: архитектура сети (CNN, Transformer) — грубая форма программы
35|35|3. **Ищем решение**: backpropagation + SGD ищут в непрерывном пространстве весов программу, которая достигает цели
36|36|
37|37|Программист 2.0 — это не тот, кто пишет код, а тот, кто **собирает, чистит и размечает данные**.

41|41|## Примеры перехода (2017)
42|42|
43|43|| Область | Было (1.0) | Стало (2.0) |
44|44||---------|------------|-------------|
45|45|| **Computer Vision** | Ручные фичи + SVM | CNN (ImageNet → архитектуры ищутся автоматически) |
46|46|| **Speech Recognition** | GMM + HMM + препроцессинг | Нейросети (end-to-end) |
47|47|| **Speech Synthesis** | Склейка аудиофрагментов | WaveNet (генерирует raw audio) |
48|48|| **Machine Translation** | Фразовые статистические модели | Multilingual нейросети (один model → любой язык) |
49|49|| **Игры (Go)** | Ручные правила и эвристики | AlphaGo Zero (только доска → ход) |
50|50|| **Базы данных** | B-Tree (кэш-оптимизированные) | Learned Index Structures (+70% скорости) |
51|51|
52|52|> Google — лидер перехода: «переписывает большие куски себя в Software 2.0».

56|56|## Преимущества Software 2.0
57|57|
58|58|1. **Вычислительная однородность** — 90% операций: умножение матриц + ReLU. Гораздо проще, чем пёстрый набор инструкций CPU.
59|59|2. **Легко внедрить в железо** — ASIC, нейроморфные чипы. Маленький чип = ConvNet + распознавание речи + синтез речи в одном «протомозге».
60|60|3. **Константное время выполнения** — каждый проход сети — одинаковое число FLOPS. Нет вариативности путей выполнения, нет бесконечных циклов.
61|61|4. **Константная память** — нет динамического выделения, нет утечек, нет свопа на диск.
62|62|5. **Портативность** — последовательность матричных умножений легко запустить где угодно.
63|63|6. **Гибкость** — нужно в 2× быстрее? Убрал половину каналов, переобучил — готово. Больше данных/вычислений? Добавил каналы — работает лучше.
64|64|7. **Модули сливаются в оптимум** — два независимо обученных модуля можно дообучить вместе через backpropagation. Представьте: браузер авто-оптимизирует низкоуровневые системные вызовы для ускорения загрузки страниц.
65|65|8. **Лучше человека** — нейросеть выдаёт лучший код, чем любой программист, в задачах с картинками, видео, звуком и речью.
66|66|

69|69|## Ограничения
70|70|
71|71|- **Непрозрачность**: 99% точности vs 90%, но непонятно как. Выбираем между понятной и точной моделью.
72|72|- **Неинтуитивные ошибки**: сеть может «тихо провалиться» или перенять смещения из данных.
73|73|- **Adversarial examples**: специально созданные входы ломают сеть неожиданным образом.
74|74|- **Сложность анализа**: миллионы весов невозможно проинспектировать вручную.

78|78|## Прогнозы (2017)
79|79|
80|80|### Инструменты 2.0
81|81|- **IDE для Software 2.0**: подсветка mislabeled примеров, автопредразметка, подсказка «какие примеры добавить»
82|82|- **GitHub для Software 2.0**: репозитории = датасеты, коммиты = добавление/правка меток
83|83|- **Package Manager для сетей**: conda/pip для нейросетей — деплой, версионирование, композиция
84|84|
85|85|### Куда движемся
86|86|- Software 2.0 займёт все области, где **дёшево оценить результат** (классификация, игры) и **сложно написать алгоритм вручную**
87|87|- **AGI будет написан на Software 2.0** — не вручную, а обучен

91|91|## Актуализация (2024-2026)
92|92|
93|93|Спустя 7+ лет:
94|94|
95|95|- **LLM — это Software 2.0 в чистом виде**: никто не пишет правила языка — модель обучается на триллионах токенов
96|96|- **Датасеты стали главным активом**: GPT-4, Claude, Gemini — соревнуются не архитектурами, а качеством данных
97|97|- **Инструменты 2.0 появились**: Hugging Face (GitHub для моделей), датасет-хабы, RLHF как способ «программирования данными»
98|98|- **Cursor, Copilot** — мост между 1.0 и 2.0: AI пишет код 1.0, но сам является продуктом 2.0
99|99|- **Adversarial examples** всё ещё актуальны — jailbreak LLM работает по тому же принципу
